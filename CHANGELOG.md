# Changelog

All notable changes to each product are documented here. Products are
versioned independently and tagged as `{product}/vX.Y.Z`.

## Unreleased

The repository was reset around each product's own purpose: shared
verification infrastructure and all previously published releases and tags
were removed, and each product now carries its own native build, test, and
release path. Product baselines will be tagged as `{product}/v0.1.0` when the
new release pipeline is in place.
